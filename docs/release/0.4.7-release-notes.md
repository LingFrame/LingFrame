# 灵珑·含章-v0.4.7 发布说明

**版本**：0.4.7

**代号**：含章

**版本线**：0.4 小版本更新，沿用“含章”代号

**发布分支**：`v0.4.7-release`

## 本次更新

### 治理结果与生命周期稳定性

- 修复 `GOVERN_ONLY` 将治理准入探针误计为真实业务结果的问题，真实结果由适配层在业务终态回灌。
- 延长异步调用准入凭据到 `CompletionStage` / `Future` 终态，统一处理成功、异常和取消，并确保结果只回报一次。
- 修复熔断器降级与恢复状态的运行时闭环，避免治理拒绝或重复结算污染熔断状态。
- 使运行时协调器启动、停止幂等；启动失败时回滚已经注册的监听器。
- 修复 JAR 缓存处理的 JDK 8 兼容性，保持 Spring Boot 2 / 3 双栈构建一致。

### 发布物可靠性

- Dashboard 明确排除本地 Tailwind 构建工具、输入样式和更新脚本，避免这些开发工具进入运行包和 `sources.jar`。
- 发布包不再携带本地前端构建二进制，减少 Maven Central 制品体积。

## 兼容性与验证

- 默认验证路径：Spring Boot 2.7 / JDK 8。
- 支持线：Spring Boot 3.5 / JDK 17。
- 推荐执行：`mvn -B clean verify -Pspring-boot2,integration-check`。
- 重点回归：`GOVERN_ONLY` 结果回灌、异步准入终态、熔断降级恢复、运行时协调器启动停止和 Dashboard 发布物清单。

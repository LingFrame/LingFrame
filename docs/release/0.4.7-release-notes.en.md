# LingFrame · Hanzhang · v0.4.7 Release Notes

**Version**: 0.4.7

**Codename**: Hanzhang

**Release line**: minor update on the 0.4 line; the Hanzhang codename is retained

**Release branch**: `v0.4.7-release`

## What changed

### Governance outcomes and lifecycle stability

- Fixed `GOVERN_ONLY` treating an admission probe as a real business outcome; adapters now report the real outcome when the business call terminates.
- Keep asynchronous admission leases until `CompletionStage` / `Future` termination, consistently handling success, failure, and cancellation with exactly-once outcome reporting.
- Closed the circuit-breaker degraded and recovery loop and prevented governance rejections or duplicate settlement from polluting circuit state.
- Made runtime coordinator start and stop idempotent, rolling back listeners when startup fails.
- Fixed JAR cache handling for JDK 8 compatibility and kept the Spring Boot 2 / 3 dual-stack build consistent.

### Publication artifact reliability

- Explicitly exclude local Tailwind build tools, input stylesheets, and update scripts from Dashboard runtime and source artifacts.
- Published artifacts no longer carry local frontend build binaries, reducing Maven Central artifact size.

## Compatibility and verification

- Default verification path: Spring Boot 2.7 / JDK 8.
- Support line: Spring Boot 3.5 / JDK 17.
- Recommended command: `mvn -B clean verify -Pspring-boot2,integration-check`.
- Regression focus: `GOVERN_ONLY` outcome reporting, asynchronous admission termination, circuit-breaker recovery, runtime coordinator start/stop, and the Dashboard publication file list.

# 灵珑·含章-v0.4.6 发布说明

**版本**：0.4.6

**代号**：含章

**版本线**：0.4 小版本更新，沿用“含章”代号

**发布分支**：`v0.4.6-release`

## 本次更新

### 路由与运行时治理

- 支持契约级权重原子覆盖、修订校验与控制面批量发布，并提供结构化路由命中事实。
- 支持实例级接流管控、局部版本路由和实例代次运行状态快照。
- 路由命中、卸载和治理操作结果关联实例代次并支持持久化。
- 拒绝不可接流的全局 Provider，统一显式版本路由约束。
- 修复事务清理与卸载重试，延长异步调用准入至任务终态。
- 支持按实例代次执行卸载清理。

### 弹性治理开关

- 超时、舱壁、限流和熔断默认开启。
- 支持运行时统一关闭或分别关闭弹性治理组件。
- 关闭组件时清理对应运行时状态，类加载器和生命周期治理保持启用。
- Spring Boot `LingFrameProperties` 与虚拟灵元配置同步暴露上述开关。

### Dashboard 与可观测性

- 展示真实路由命中、实例代次、卸载清理、持久化恢复、备份、审计和治理操作结果。
- 持久化并查询控制面审计事实，前端操作接入原子路由和真实运行证据。
- 默认关闭高风险演练能力。
- 修正双栈构建脚本的 Spring Boot 3 输出目录处理。

## 兼容性与验证

- 默认验证路径：Spring Boot 2.7 / JDK 8。
- 支持线：Spring Boot 3.5 / JDK 17。
- 推荐执行：`mvn -B clean verify -Pspring-boot2,integration-check`。
- 发布分支从最终发布提交创建，不再回合并到 `main`。

# LingFrame · Hanzhang · v0.4.6 Release Notes

**Version**: 0.4.6

**Codename**: Hanzhang

**Release line**: minor update on the 0.4 line; the Hanzhang codename is retained

**Release branch**: `v0.4.6-release`

## What changed

### Routing and runtime governance

- Added atomic contract-weight overrides, revision validation, batched control-plane publication, and structured route-hit facts.
- Added instance-level traffic admission control, local version routing, and instance-generation runtime snapshots.
- Route hits, unloads, and governance-operation results now carry instance-generation context and support persistence.
- Reject globally registered Providers that cannot accept traffic and enforce explicit version-routing constraints.
- Fixed transaction cleanup and unload retries, extended asynchronous admission through task termination, and added generation-scoped unload cleanup.

### Resilience switches

- Timeout, bulkhead, rate limiting, and circuit breaking are enabled by default.
- Applications can disable resilience globally or disable individual components at runtime.
- Disabling a component clears its runtime state while class-loader and lifecycle governance remain enabled.
- Spring Boot `LingFrameProperties` and virtual-Ling configuration expose the same switches.

### Dashboard and observability

- Expose real route-hit facts, instance generations, unload cleanup, persistence recovery, backups, audit facts, and governance-operation results.
- Persist and query control-plane audit facts, and connect frontend operations to atomic routing and real runtime evidence.
- Disable high-risk rehearsal capabilities by default.
- Correct the Spring Boot 3 output directory in the dual-stack build scripts.

## Compatibility and verification

- Default verification path: Spring Boot 2.7 / JDK 8.
- Support line: Spring Boot 3.5 / JDK 17.
- Recommended command: `mvn -B clean verify -Pspring-boot2,integration-check`.
- The release branch is created from the final release commit and is not merged back into `main`.
